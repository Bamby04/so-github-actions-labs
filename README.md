## Descripción

Este repositorio contiene workflows de GitHub Actions para ejecutar pruebas de verificación del sistema en múltiples plataformas: Ubuntu, Windows y macOS.  
El objetivo es validar que el sistema tenga las configuraciones necesarias y comprobar que los workflows funcionan correctamente.
